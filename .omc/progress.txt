## Key Technical Decisions
- PHP 8.4 minimum requirement for modern features
- PHPUnit for testing framework
- PHPStan level 9 + Psalm for strict type checking
- Mersenne Twister (mt_rand) for seedable RNG engine
- Value objects for immutability (DieResult, RollResult, etc.)
- Interface-based design for extensibility
- Extensible parser architecture for future notation additions
